## 当前进度

已建立分支并保存设计基线。来源身份加入会话、存储关联、状态映射、HTTP 路径和浏览器引用。

本地来源在一个 Hub 内使用保留身份 `local`，远程来源由配对分配独立身份。
`local` 是持久的本地来源槽位，不表示当前进程是否启用采集；其全局归属还包含 Hub 身份。
旧会话与用户状态分别迁移时均映射到该保留身份，不需要跨库生成两次 UUID。
旧单机转远程 Worker 时，在发送入口映射到配对身份，不将 `local` 作为远端授权身份。
默认本机引用在 wire 中可省略来源，保留旧 URL 和游标；远程 URL 显式包含来源。

来源身份阶段已运行一次核心库测试：194 通过，3 个原有忽略项；后续新增迁移测试及 HTTP/前端变更仍在验证。
